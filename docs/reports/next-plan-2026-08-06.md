## Track A — ปิดช่องที่ repository อนุมัติตัวเองได้ (บล็อกทุกอย่าง)

### A1. Trusted lifecycle-executable permission gate  ⚠️ ทำก่อนสุด

**ปัญหา:** `.changeloop/proof-providers.json` และ `.changeloop/reviewer.json`
เลือก executable + argv ได้เมื่อผู้ใช้สั่ง `prove` / `review` ทั้งที่ repository ถือเป็น
untrusted content ปัจจุบัน shared runner ล้าง environment แล้ว แต่ยังมี host
filesystem/network authority เต็ม แปลว่า clone repo แปลกหน้าแล้วสั่ง `cloop prove`
= รันโค้ดของคนอื่นบนเครื่องตัวเอง

**ต้องทำ:**
- exact executor approval ที่ bind ครบ: canonical root + workspace revision,
  config digest, executable path **และ bytes hash**, ordered argv, environment,
  timeout/output caps, sandbox profile, writable paths, network policy, change/session
- provenance เป็น one-shot จาก user หรือ trusted policy เท่านั้น —
  repository content อนุมัติตัวเองไม่ได้ (fail-closed)
- proof/repair/reviewer runner ต้องวิ่งผ่าน `changeloop-sandbox` เหมือน MCP/extension
- reviewer model family และ accepted-risk authority มาจาก trusted attachment แยก
  **ห้าม** รับค่าที่ reviewer process self-report ทาง stdout
- ใช้ policy engine เดิม ไม่สร้าง permission plane ที่สอง

**Evidence:** regression ที่ commit ไฟล์ config ชี้ไป executable อันตรายแล้วยืนยันว่า
`prove` ปฏิเสธโดยไม่ spawn · test ที่ยืนยันว่า approval ที่ผูกกับ digest เดิม
ใช้ซ้ำกับ argv ที่แก้แล้วไม่ได้ · test ว่า reviewer stdout ยกระดับ authority ตัวเองไม่ได้

### A2. Authenticated evidence store

**ปัญหา:** workspace revision ตัด `.changeloop` ออกทั้งหมด แต่ executor config
และ operational/proof/review authority artifacts อยู่ในนั้น → ไม่มีอะไรกัน
evidence forgery/replay

**ต้องทำ:** ย้าย operational/evidence authority ไป authenticated SQLite หรือ
signed/MAC record และรวม trusted config digest เข้าไปใน proof/review freshness

**Evidence:** test ที่แก้ receipt บนดิสก์แล้ว Land ต้องปฏิเสธ · test replay receipt เก่า

### A3. ปิด Land TOCTOU window

**ปัญหา:** Land ยังมี same-user parent-directory swap window ใน path-based
remove/create/rename ขณะที่ snapshot restore ปิดไปแล้ว

**ต้องทำ:** ย้าย traversal/mutation ไป pinned dirfd + `openat`/`renameat`/`O_NOFOLLOW`
แบบเดียวกับ snapshot

**Evidence:** adversarial test สลับ parent directory ระหว่าง traversal กับ mutation

## Track B — Durability ของข้อมูลผู้ใช้

### B1. Two-phase journal สำหรับ mutation

undo/redo ชดเชย ordinary save failure ได้แล้ว แต่ process/power crash ระหว่าง
file mutation กับ manifest commit ยังไม่มีอะไรกู้ ต้องมี prepared / applying /
committed journal และ snapshot cleanup ต้อง commit manifest ใหม่ก่อน blob GC
(หรือใช้ two-phase journal เดียวกัน)

**Evidence:** crash injection ทุก phase แล้ว recover ได้ครบทั้ง workspace, cursor,
redo stack และ audit state

### B2. `privacy delete` inventory ให้ครบจริง

ตอนนี้ลบ SQLite / operational / privacy index แต่ **ไม่ลบ** snapshot, proof, review,
hook, archive/Land artifacts และ purge lock ไม่ร่วมกับ lifecycle writers

**ต้องทำ:** exact content-bound inventory, unified writer lock ที่ lifecycle writers
ใช้ร่วม, journaled nofollow quarantine

**Evidence:** test ที่ยืนยันว่าไม่มี raw bytes ของ prompt ที่ลบแล้วเหลือใน artifact ใด ๆ

### B3. Hardening backlog

SQLite `synchronous=NORMAL`, pre-write quota check, DNS resolver worker exhaustion,
migration `lstat`→path-open TOCTOU — งานย่อย แยกเป็น change ละตัวได้

## Track D — Capability

### D1. เปิด runtime wiring ของ app-server ให้ public (งานเล็ก ทำก่อน D2)

ทำ `RuntimeTools` / `RuntimeGate` / `RuntimeProvider` ให้ public พร้อม read-only
constructor เพื่อยุบ wiring สองชุดที่ถือ authority model เดียวกันให้เหลือชุดเดียว
ตอนนี้ ACP driver ประกอบ runtime อ่านอย่างเดียวของตัวเองจาก public crate

### D2. ACP write path

ACP ตอนนี้อ่านได้ สนทนาได้ ตอบ permission ได้ แต่เขียน/รัน shell/รันเทสไม่ได้ —
ถูกปฏิเสธ 4 ชั้น การเปิดต้อง route ผ่าน change-confirmation path ของ cloop
(draft → confirm → prove → land) ซึ่งเป็น **design decision** ไม่ใช่แค่ต่อสาย
คง `allow_always` ไว้ว่าไม่มีเหมือนเดิม เพื่อไม่ให้ ACP client เก็บ standing grant

**ต้องทำหลัง A1** เพราะเป็นการขยาย authority surface

### D3. `BoundedResourceCache`

ยังไม่มีผู้ใช้จริง — `ResourceKind::Cache` ลงทะเบียนไว้ด้วยชื่อเท่านั้น
เลือกอย่างใดอย่างหนึ่ง: หา user จริงให้มัน หรือถอดการลงทะเบียนออก
