ต้องการ improve workflow 
อยากให้ช่วยอ่านว่า ควรปรับอะไรที่ไหน skill ไหน templates ไหน command ไหน agent ไหน

phase of work 
1. Plan
    - ทำความเข้าใจ requirement or problem
    - เสนอความเป็นไปได้
    - ถามหาก requirement or problem ไม่เข้าใจหรือไม่ครบ
    - สร้าง spec
2. Analysis
    - read docs ที่เกี่ยวข้อง
    - read codebase ที่เกี่ยวข้อง
    - analysis ว่า ทำได้ไหม 
    - ถามหากไม่เข้าใจ
    - เสนอความเป็นไปได้
3. Design
    - ออกแบบ overview
    - ออกแบบ architecture
    - ออกแบบ domain
    - ออกแบบ feature and user story and scenario
    - ออกแบบ test plan
    - diagram ต่างๆ apiflow , sequece diagram และที่ต้องใช้
    - เสนอ plan
4. implement
    - analysis plan 
    - breakdown plan to task
    - implement follow plan 
    - ตรวจสอบความถูกต้องของ code
5. intergration and testing
    - intergration จุดเชื่อมต่อกันทั้งหมด 
    - testing follow test-plan
6. review 
    - review code ที่แก้ทั้งหมด หลายมุมมองตามรูปแบบงาน
    - แก้ไขจำเป้นต้องแก้ไข
7. update docs
    - update document ของเอกสารในระบบทั้งหมดที่เกี่ยวข้อง
8. ship
    - commit and push or no commit
