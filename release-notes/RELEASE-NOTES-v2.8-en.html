vs. other spec workflows (spec-kit, agent-os, …)

  • Type-aware + size-aware, not one-size-fits-all — fix/refactor/spike/docs each take a different path; XS work gets a single-spawn patch lane. Most alternatives run full machinery on everything
  • Enforcement is code, not hope — most alternatives are prompt-only; this ships 4 PreToolUse/PostToolUse hooks with a 68-assertion test suite over the hooks themselves
  • Model-tier economics built in — haiku/sonnet/opus pinned per role, guard-enforced, one policy file (model-tiers.md) — opus is spent only where it pays
  • Skills are on-demand references — the always-on layer is ~1.3k words; 26 skills load only when triggered, and after v2.8.1 each load costs ~⅓ of what it did
  • Trade-offs are written down — every correctness-for-context shortcut is documented with a backstop (spot-check, near-miss peek), not silent magic

Our weaknesses (plainly)

  • Higher per-run overhead than vanilla — a full M/L run costs multiples in tokens and time; worth it when the blast radius is real, not for quick hacks (which shouldn't enter /dev anyway)
  • The prompt-side state machine has no regression test yet — hooks are tested; the orchestrator flow is proven by use. A golden-run smoke test is planned for v2.9
  • Multi-repo writes one repo at a time — read/review/security fan out across repos, but implement/ship stay pinned to the primary by design; cross-repo findings go to a human
  • Tied to recent Claude Code — direct nesting needs v2.1.172+, and the conventions carry a learning curve before your first run reads fluently
  • Spec quality depends on interview answers — the system grills, but garbage answers still produce ceremonial garbage
  • team-* reviewers are detached from upstream — pipeline coherence gained, automatic pr-review-toolkit improvements lost

🛡️ Real hook bugs fixed v2.6.9

Two silent fail-opens hiding inside the state-protection machinery — found by the full audit

  • Dup-key check is indent-proof — the old check grepped only 2-space-indented keys, so any reformat silently defeated the guard behind a real --resume-breaking regression. Now python3 object_pairs_hook: catches every indent, nested dups included
  • Guard Case 4 fails closed — an unreadable worker model: pin used to crash the hook and wave the spawn through; now it refuses with a clear reason
  • Docs match reality — the concurrent-run fail-open caveat, test-plan folding into the fast path, the surface-fanout axis in WORKFLOW.md

⚡ Opus 4.8 profile + model tiers v2.7.0

Closing the self-verification gap with external feedback — the condition under which benchmarks show 4.8 matching higher tiers

  • artifact-lint.sh --hook — every artifact write under .workflow/ gets an instant warn-only lint (never blocks) — leftover placeholders and missing sections surface while drafting
  • lint.sh typechecks — .ts/.tsx via the nearest tsconfig (diagnostics filtered to the edited file), .py via pyright — immediate error feedback after every edit
  • Review recall fix — team-code-reviewer no longer pre-filters to confidence ≥ 80 (models over-obey "don't be nitpicky" and drop true positives); it reports everything scored, and lead gates at synthesis where cross-worker context lives
  • Review fanout default-ON at M/L — turning it off needs a stated reason, not a cost reflex
  • model-tiers.md — the whole tier policy in one file, plus an env-tunable floor for the generic built-ins
  • Forks declared DETACHED — the team-* reviewers evolve with this pipeline, not upstream

⚖️ Correctness margins restored v2.7.1

Three context-saving shortcuts that used to trade away safety

  • Gate-fold spot-check — a shard listing every AC no longer passes on its own say-so: one AC is verified in the actual artifact (a single grep) before the fold passes
  • Security near-miss peek — a name-only trip (rename, comment sweep) earns one bounded look before deciding; any doubt still fires
  • Failure-aware capture — red test runs re-capture tail -200 instead of starving diagnosis at 40 lines

🧹 Consolidation v2.7.2

  • Recruit-help contract 7 → 1 — the nesting contract that was copy-pasted across seven files now lives once in dispatch-mechanism.md

✂️ Complexity cut v2.8.0

Removing what the model had to hold in its head without payoff

  • Phase names replace dual numbering — 26 files stop cross-referencing "Phase 2 step 4" / "op 12"; the hand-maintained translation table is gone entirely
  • One signal shape: implement: — every splittable worker direct-nests its own helpers now, so the five read-side signal shapes (review/security/plan/test/research) were a redundant second path — retired
  • Review lenses 6 → 4 — simplifier + comment-analyzer folded into team-code-reviewer as lenses; two fewer spawns per L review, no checklist lost
  • fanout_log records outcomes, not non-events — ineligible fanout points log nothing
  • First five skills slimmed — ddd-strategic, delivery-engineering, security-fundamentals, queue-fundamentals, skill-creator → ~1.1k words each
