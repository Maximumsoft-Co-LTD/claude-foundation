# Orchestrator reference — Phase 1 (Requirements)

> Loaded on demand by the main agent (`.claude/orchestrator.md`). Ops **2–4**: Interview →
> Design → Gate. Read it when a fresh run starts. **`/implement` needs only op 4** (the
> gate) — the run it resumes already has its spec/plan; skip ops 2–3.

2. **Interview (you run it).** Ingest prior conversation into a **requirements digest**, estimate `size` + classify `field`, fetch reference URLs, run spec-prep fanout (opt-in), pick the UNSPECIFIED slots **ordered by the design tree** (load-bearing first, defer dependents to a later batch), run the three detections (NFR / e2e-visual opt-in / error-boundary), `AskUserQuestion` **one batch of 3–4 — each choice leads with a `(Recommended)` option** — + a free-text catch-all, save the bundle for `pm`. Procedure → `references/interview.md`.
3. **Design (spec + plan + tasks + test-plan — one artifact set, size-routed).**
   **Execution mode first** (`references/size-execution.md > Execution mode`): substantial pre-work resident this session (POC / extended spec discussion) → draft Phase 1 **warm** — `fork` yourself (guard-sanctioned in `phase-1-requirements`, so the fork inherits that context instead of a lossy digest; inline for XS/S) and write the resolved artifact shape directly, returning paths + summary — **no cold pm/lead spawn**, no digest hand-off. Thin pre-work / L parallel slices → the cold-spawn path (b/c). Record `exec_mode`. Sub-steps b/c below are the **cold** path; the warm drafter follows the same shape + checks (d).
   a. **Context (brownfield M/L — shared understand map).** `field=brownfield` AND `size∈{M,L}` → build `.workflow/<id>/context.md` once via `team-codebase-explorer`, set `context_built=true`, and pass it to b/c instead of letting each slice re-walk. Procedure (dispatch shape, M-before-combined ordering, ledger seeding, evidence-not-authority rule) → **`references/ml-design-chain.md > Context`**. Greenfield / XS / S → skip; the slices cold-walk.
   b. **XS/S — inline, no spawn. M — one combined `lead` spawn (fast path).**
      **XS/S:** write the artifact set yourself following `.claude/agents/references/lead.md > Combined variant` (XS: the single `run.md`; S: the four files) at the **resolved artifact shape** for this Type (`plan-writing > references/size-tiering.md > Artifact shape by Type`) — same sections, same depth, same reference access a spawn would have had. You already hold the digest, Q&A, intent and the size/field call; a cold spawn re-reads a 29 KB brief to re-derive them, and it measured **39–49% of a brownfield-S run's wall clock**. Escalate to the cold `lead` spawn on a risk flag the size call missed (persisted data beyond the run's own store, schema, public API/event contract, trust boundary, cross-repo) — that is `SIZE_UPGRADE: M`. Record `exec_mode.design=inline`.
      **M:** spawn `lead` combined mode: spec+plan+tasks+test-plan in one spawn — pass `Type`, the resolved artifact shape (name the required blocks in the brief so `lead` never guesses), digest + full Q&A + references + `context.md`/spec-prep findings when built; **model opus** (spec quality rides the plan spawn). No further plan-prep fanout (Context covered it). `lead` direct-nests any residual best-practice research itself (no signal).
   c. **L — full chain.** Three sequential spawns instead of the combined one: `pm` (spec) → plan-prep fanout unless `context_built` → `lead` plan mode (**opus**) → `qa` test-plan mode (feat/fix/refactor; else append `test-plan` to `skipped_steps`). Full brief contents per spawn → **`references/ml-design-chain.md > L full chain`**.
   d. **Checks + bookkeeping (all paths — on the returned artifacts).** **Spec check** (`spec.md`): `Type` set; User Stories (priority-ordered) + acceptance scenarios (`AC#`) + FR-### + SC-### present; each fired section's trigger holds; `fix` has concrete Reproduction; `spike` has hard Timebox; unresolved slots marked — re-spawn only if a real answer was dropped. **Plan check** (`plan.md` + `tasks.md`): `tasks.md` has ≥ 1 `T###` task with an `[AC#]` tag + `verify:`; `plan.md` has a `## Phases for this task` block; no `[NEEDS CLARIFICATION]` — fail → re-spawn once, then escalate. **Test-plan check:** missing first line when type should produce one → re-spawn once; `BLOCKER:` → `AskUserQuestion`, route to pm/lead. INDEX → `planned`. State: L path writes per artifact (`step=spec` → `plan` → `test-plan`); combined path one write after the checks (`step=test-plan`, or `plan` when the type skips test-plan), `next_step=gate`.
4. **Gate.** **Fold Phase-1 shards first** (read each `state.*.json`, fold into `state.json`, re-emit once). **Test-plan backfill:** `pending_plan_backfill` (or `[pending plan]` remain) AND `plan.md` now exists → fill **once** first — **XS/S inline** (read `plan.md`/`tasks.md`, write the rows; no spawn), **M/L** re-spawn `qa` `backfill`. **Pre-gate consistency scan — set-compare first:** spec AC set vs each shard's `ac_covered` (plan=`tasks.md` tags · test=Coverage rows · uxui=Scenes) → **match → spot-check the highest-numbered AC in the artifact (one grep — `references/team-mode-sharding.md`) → holds → pass, no re-read.** Mismatch, failed spot-check, or no `ac_covered` → re-read that artifact + full check: every AC has delivering+verifying task(s) tagged in `tasks.md`, no dangling `T###` / phase ref, zero `[NEEDS CLARIFICATION]`, (feat/fix/refactor) every AC has a Coverage-plan row and no `[pending plan]` rows. Fail → one corrective re-spawn of the owner. Build the type-aware run plan from the matrix; **resolve ship disposition** — `commit_on_ship` **asked every run (default `no`)**, then `open_pr_on_ship` only if commit=yes (blank → ask once; commit=no forces it `no`); then **present the contract and run the option loop** → `references/gate.md`. Loops until `approve`; free-form = `revise` for this run.
