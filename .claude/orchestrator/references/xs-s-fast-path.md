> Loaded on demand by the main agent (`.claude/orchestrator.md`). Read it when `size` ∈ {XS, S}. Everything not listed here runs as written in the main flow.

- **One question batch.** Fold setup + interview into one `AskUserQuestion` (≤4, catch-all last). Over 4 → drop the type question (record as `Assumptions (inferred)`), then branch (propose in intro); never drop an interview slot or the catch-all. Checkout right after. **Say the path** in the status line + gate summary (e.g. "Size: XS → fast path: combined spec+plan, merged docs+ship, inline retro").
- **Spec+plan+tasks+test-plan in one spawn.** Skip `pm`; spawn `lead` combined mode (`.claude/agents/references/lead.md > Combined variant`) with digest + Q&A; the spec/plan/tasks/test-plan checks run on the returned artifacts. **Clean-tree check after return:** `git -C <repo_root> status --porcelain` — any source change means lead implemented early; revert, note, proceed. Test plan folds in (feat/fix/refactor; gate surfaces it, pre-gate scan still checks each AC has a Coverage-plan row; chore/docs/spike → append `test-plan` to `skipped_steps`). Handle return first line (`SIZE_UPGRADE`/`FIELD_UPGRADE`/`BLOCKER`).
- **Test inline** (feat/fix/refactor, `e2e_visual=off`): the engineer implemented the planned tests (engineer Mode A rule); run the **Impacted** cmd from `test-plan.md > Commands` via Bash yourself and write `tests.md` from the template — one row per Coverage-plan AC + result, Commands, (fix) the pre-fix-fail evidence from the engineer's two-commit sequence. Failing → route to `engineer` (`cycles.test++`, limit 3, unchanged). `e2e_visual=on` → spawn `qa` as usual.
- **Review stays, fanout doesn't** — `lead` attempting to direct-nest review helpers on XS/S is itself evidence of a size-upgrade; return `SIZE_UPGRADE:` instead. **Docs+ship in one spawn** (Mode B then C); Implement stays its own spawn.
- **Skipped-test stub inline** for chore/docs (write `tests.md > Skipped` yourself). **Retro: XS/S inline** (stamp `done_at` first, write `retro.md` from template yourself + update INDEX/FOLLOWUPS; skill round only if something surfaced).
