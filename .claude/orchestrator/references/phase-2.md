5. **Implement.** Run the resolver. XS and genuinely small warm work stay inline. Before coding, count code-producing tasks and expected source/test files; ≥3 of either, a planned test-fix loop, or >~2K expected generated tokens fires execution volume → spawn one bounded `engineer` at its Sonnet pin (`exec_reason.implement=model-economy:<signal>`), even when main holds the map. Pass `tasks.md > Guardrails`, task/AC ids, named anchors, and context pointer, not the full conversation. **Inline does not load `engineer.md`:** execute the same lazy task contract locally. L alone never selects Opus; pass `model="opus"` only for a named high-stakes implementation trigger from `model-tiers.md`. Fork remains blocked. INDEX → `building`; state `step=implement`. Resume/diff/fanout → guards Implement.
6. **Change Gate — Test (runs before review).** For feat/fix/refactor, `phase_plan.test == "skip"` is invalid: restore `run` and surface a state/plan inconsistency. Known Impacted command, existing harness, and `e2e_visual=off` run inline at **any size** (`exec_reason.test=known-runner`). Write `tests.md` with one authoritative row per AC and `Status: impacted-passing|failing`. Spawn `qa` only for browser/e2e, a new/unknown harness, multi-repo coordination, or an independent test-contract investigation; record which proof fired. chore/docs write a skipped stub; spike skips. Failing → `cycles.test++`, route to the current Implement executor and re-enter Test; limit 3. Detail → guards Test.
7. **Change Gate — Review + Security (the security check always runs).** Compute changed repos and run the trigger scan first. A fired Security trigger always runs isolated Review+Security. Otherwise, Review is mandatory for runtime-behaviour M/L or a volume-routed Sonnet implementation: at S, main is independent from the Sonnet author and reviews inline; at M/L, use one independent `lead`. If Review is optional by Type, `phase_plan.review=skip`, and no mandatory trigger fired, record the skip and continue. Mechanical/docs/config work may review inline. Review consumes `tests.md`, checks task adherence + semantic/contract risks, and never reconstructs every AC result. Fix → Implement → targeted Test → delta Review; limit 2.
8. **Ship (Ship Gate → docs → ship).**
   a. **Ship Gate** (feat/refactor/fix; pre-docs). Change Gate clean → run **Full-suite** plus recorded lint/type/static commands once via Bash (no `qa` re-spawn) = authoritative ship-blocking `passing`; inner loops (ops 6–7) ran **Impacted** only. Green → `ship gate: green` → docs. Red → `cycles.test++` (≥3 escalate) → `engineer` → re-enter Test targeted, then rerun Review only for changed risk scope and Ship Gate on the new converged diff. No code test surface is a blocking test-plan gap, not a skip. Detail → guards `Ship Gate`.
   b. **Docs touch-up.** Skip when planned. Small README/JSDoc/release-note updates are deterministic and inline at M/L. Spawn `engineer` only for a new page, substantial restructure, or documentation requiring an independent source walk. S keeps its merged Docs+Ship exception.
   c. **Ship.** Stage/commit/push/PR commands are deterministic and inline at M/L; `commit_on_ship` still governs effects and existing git safety rules still apply. Spawn `engineer` only when Ship needs an isolated multi-repo/CI investigation, not for ordinary git commands. Validate SHA/PR/ready command yourself.
9. **Close (retro → skills → summary).**
   a. **Retro.** Stamp `done_at` first and write inline at every size without loading `retro.md`: fill the template from state + test/review/security outcomes + diff stat; update FOLLOWUPS; fold still-true context, green validated commands, ticked capabilities, and architecture decisions; update INDEX. Open a source artifact only for a missing field. Spawn `retro` only for substantial multi-repo/deep synthesis; record that proof. State → skill-handoff.
   b. **Skill-candidate handoff.** Per candidate `retro` surfaced, `AskUserQuestion` whether to create; approved → invoke `skill-creator` with its handoff prompt; record outcomes. Memory candidates saved per the standard protocol, not gated here.
   c. **Done.** Print summary: artifacts, files changed, commit, PR, open follow-ups, skills created. State `phase=done, step=done`.
