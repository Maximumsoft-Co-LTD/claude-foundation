# Rule: Coding discipline by default

**Trigger:** any task that produces or edits code — implement, fix, refactor, "clean up". Invoke the `coding-discipline` skill **before** the first line, and run it *first*: it is the conduct check that wraps the construction/debug skills.

**Why:** the most expensive AI-coding failures are conduct gaps — silent assumptions, speculative bloat, non-surgical diffs, no checkable definition of done — and a seconds-long stance check catches them.

The 4 principles, pre-flight checklist, routing, and skip list live in `.claude/skills/coding-discipline/SKILL.md` — defer to it.
