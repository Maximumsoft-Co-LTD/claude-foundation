# Bug #731 — boolean seat counts bypass workspace validation

Production received `{"seat_count": true}` on the workspace-creation API.
Python treats `bool` as a subclass of `int`, so the validator accepted the
value as one seat and created an invalid workspace record.

Fix the validation defect. The public functions and response shapes must remain
compatible. Add a regression test for the reported representation boundary.

- `seat_count` must be an exact integer, not a boolean, float, or numeric string.
- Valid seat counts are 1 through 100 inclusive.
- `marketing_opt_in` remains an optional boolean and defaults to `false`.
- Validation belongs in `validate_workspace`; other callers use it directly.
