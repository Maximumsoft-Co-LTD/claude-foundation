# Bug #412 — "hide the activity strip" shows everything instead

Support ticket: a workspace set its activity-strip window to 0 to hide the
strip. Instead of showing nothing, the strip came back with the workspace's
entire event history — 900+ rows — and the page hung.

Repro: `activityStrip(events, 0)` with any non-empty `events`.
Expected: no rows at all.
