Write a debounce utility in this repository. debounce(fn, ms) returns a debounced function. Requirements — AC1: fn fires only ms after the last call (trailing edge); AC2: rapid calls within the window coalesce into one fn call with the latest arguments; AC3: the returned function has cancel() that prevents a pending call; AC4: calls more than ms apart each fire once. Write the code and unit tests directly. Do not use any workflow, do not create planning or spec files — just implement it.
