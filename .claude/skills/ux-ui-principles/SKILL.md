# UX/UI principles

Resolve experience decisions from the user's task, observed evidence, and
product constraints; preserve working conventions and disclose unverified checks.

## Steps

1. Read `references/change-loop-handoff.md` for task scope, handoffs, evidence,
   and authority.
2. Read `references/experience-workflow.md` to pick the mode and the topic or
   layout guides to load.
3. Decide from the user's task and observed evidence; load only the matching
   topic reference.
4. State what was verified and what was not.

## Harness

Follow the active compiled OpenSpec agreement and harness action; this skill
grants no execution or delivery authority.

## References

- `references/change-loop-handoff.md` — working contract; read first.
- `references/experience-workflow.md` — modes and selective topic guides.
- `references/upstream.md` — source snapshot and adaptations.
- Hand settled visuals to `frontend-design`, shared tokens to
  `tailwind-design-system`; use `ui-ux-pro-max` for searchable design data.
