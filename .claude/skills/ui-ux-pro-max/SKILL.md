# UI/UX design intelligence

Search the bundled catalog for a direction; separate observed behavior from
assumptions.

## Steps

1. Read `references/experience-workflow.md` for the contextual checks and
   which search reference to load.
2. Run the search tool per `references/search-tool.md` against `data/` for
   product type, style, palette, typography, or chart guidance.
3. Compare concrete alternatives when a novel interaction has real uncertainty;
   keep throwaway prototypes in the harness-provided investigation scope.
4. Model loading, empty, denied, error, recovery, and success states; check
   keyboard, touch, responsive reflow, and reduced motion.
5. Prioritize findings by user impact and verify the decisive example.

## Harness

Record consequential choices in OpenSpec. Browser and accessibility providers
produce evidence; reviewer agreement or a screenshot grants no completion,
deployment, or Land authority.
